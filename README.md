# 자유의 여신상 — 카메라 Pop-out 3D

## 필요한 파일

```text
statue-liberty-popout-3d/
├── index.html
├── README.md
├── liberty-phone-background.png  # 여신상이 제거된 스마트폰/뉴욕 항구 이미지
└── statue_of_liberty_1.glb       # 기존 3D 모델
```

## 사용법

1. 네 파일을 GitHub 저장소 최상위에 업로드합니다.
2. Settings → Pages → Deploy from a branch → main / (root)를 선택합니다.
3. `https://ilmac-knu.github.io/statue-liberty-popout-3d/`에서 접속합니다.
4. `카메라 켜기`를 누르고 카메라 접근을 허용합니다.
5. `위치 배치`를 누른 다음 원하는 화면 위치를 터치합니다.
6. 한 손가락으로 콘텐츠를 이동하고, 두 손가락으로 회전·확대·축소합니다. 버튼으로도 회전·확대·축소할 수 있습니다.
7. 지원 기기에서는 `기울기 회전`으로 스마트폰 기울기에 따른 2D 회전 효과를 사용할 수 있습니다.

## 기술적 범위

- 카메라 영상 위에 **스마트폰 배경 이미지와 자유의 여신상 GLB를 하나의 그룹**으로 합성합니다.
- 배경은 실제 스마트폰이 아니라 이미지입니다. GLB는 Three.js로 별도 렌더링됩니다.
- 기울기 회전은 화면 안 콘텐츠의 2D 회전입니다. 기기 자세에 맞춘 정교한 3D 카메라 추적은 아닙니다.
- 실제 바닥/공간을 인식해 객체를 고정하는 WebXR AR은 아닙니다.
- GLB의 형상과 시점에 따라 받침대 위치·크기를 조정해야 할 수 있습니다.
- **중요:** 배경 이미지에는 자유의 여신상이 없어야 중복되지 않습니다.
- 모델 초기 배치는 index.html의 `anchor={u:.34,v:.79,height:.74}`에서 조절합니다. `u`는 가로, `v`는 세로, `height`는 이미지 높이에 대한 GLB 높이 비율입니다.
- 웹 브라우저의 카메라 권한 및 인터넷 연결이 필요합니다.
